## ب — فحص حجم مستند الشهر

## ج — اختبارات القواعد على Emulator

**شُغّلت فعلياً على Cloud Firestore Emulator. النتيجة: 61/61.**

`firebase-tools` مُدرج في `devDependencies` فيكفي `npm install` ثم `npm run test:rules`.

```bash
# 1) الأدوات (firebase-tools ضمن devDependencies — لا حاجة لتثبيت global)
npm install

# 2) التشغيل التلقائي (يشغّل Emulator ثم الاختبارات ثم يغلقه)
npm run test:rules

# أو يدوياً:
firebase emulators:start --only firestore,auth --project qama-test
node --test tests/rules/rules.test.mjs
```

الواجهة الرسومية للـEmulator: `http://localhost:4000`
