NEW FIREBASE PROJECT (Blaze)
  1. Go to https://console.firebase.google.com
  2. Create a NEW project — do not use qama-alrawasi
  3. Upgrade to Blaze (pay-as-you-go) — required for Cloud Functions
  4. Enable Authentication (any provider; login uses custom tokens)
  5. Create a Firestore database (production mode)
  6. Register a Web app; copy the firebaseConfig object

PASTE WEB CONFIG
  File: src/frontend/config.mjs
  Set USE_EMULATOR = false
  Replace every YOUR_* placeholder with values from Firebase Console > Project settings > Your apps > Web app config

FIRST OWNER (secure, one time)
  Do not use emulator demo PINs in production.
  After deploy, with a service account JSON from Firebase Console > Project settings > Service accounts:
    export GOOGLE_APPLICATION_CREDENTIALS=/path/to/serviceAccount.json
    export OWNER_PIN="choose-a-strong-pin"
    cd qama-new && npm install --prefix functions
    node --input-type=module -e "
      import { initializeApp } from 'firebase-admin/app';
      import { getFirestore } from 'firebase-admin/firestore';
      import { scryptSync, randomBytes } from 'node:crypto';
      const pin = process.env.OWNER_PIN;
      if (!pin) throw new Error('Set OWNER_PIN');
      initializeApp();
      const salt = randomBytes(16).toString('hex');
      const hash = scryptSync(pin, salt, 64).toString('hex');
      const id = 'owner:' + Date.now();
      await getFirestore().collection('users').doc(id).set({
        id, userId: id, displayName: 'Owner', role: 'owner', active: true,
        pinHash: hash, pinSalt: salt, pinUpdatedAt: new Date().toISOString(),
        createdAt: new Date().toISOString(), createdBy: 'bootstrap', schemaVersion: 1,
      });
      console.log('Owner created:', id);
    "
  Store OWNER_PIN securely; it is never saved in code.

DEPLOY
  firebase login
  firebase use YOUR_NEW_FIREBASE_PROJECT_ID
  firebase deploy --only firestore:rules,firestore:indexes,functions,hosting

OPEN DEPLOYED URL
  Firebase Console > Hosting — or:
  https://YOUR_NEW_FIREBASE_PROJECT_ID.web.app
